# Rebitishki eSports Website

A responsive, animated Dota 2 esports landing page for Rebitishki eSports.

## Files
- `index.html` — page structure and inline SVG branding/icons
- `styles.css` — red/white/black visual system, responsive layout, animations
- `script.js` — mobile menu, reveal animations, cursor glow, card tilt, nav tracking, parallax

## Run
Just open `index.html` in a browser.

For local development:
```bash
python3 -m http.server 8080
```
Then open http://localhost:8080

## Replace links
Search `href="#"` in `index.html` and replace the placeholders with your real Twitch, Discord, Faceit, YouTube, X, tournament and player URLs.

## Player artwork
The current roster cards use CSS-generated abstract portrait treatments so the page has no external image dependency. Replace each `.player-photo` block with real player photos when ready.

## Generated design reference
The supplied concept image can be used as a visual reference while customizing the page.
